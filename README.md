## Thought Process

The plan is to keep it lightweight, portable, and with as few dependencies as possible.

1. Explore [Code of Federal Regulations](https://www.ecfr.gov/)
2. Review Public API
3. Download data using API
4. Store raw json data server-side
5. Parse JSON data into a basic sqlite database
6. Create a basic PHP router
7. Create an adapter to use raw data or database
8. Create routes for API
9. Use basic HTML and TailwindCss to create front-end quickly
10. Use ChartJS to display results
